Airbnb Market Analysis using PostgreSQL & Power BI

Project Overview:
This project analyzes Airbnb listing data to uncover pricing patterns, host behavior, and location-based demand using SQL and data visualization techniques.

Tools & Technologies:
PostgreSQL pgAdmin (Data Cleaning & Analysis)
Power BI (Dashboard & Visualization)
Kaggle Open Dataset

Dataset:
Open Airbnb dataset containing listing details, pricing, availability, host information, and reviews.

Key Objectives:
Clean and standardize raw Airbnb data.
Analyze pricing trends across room types and neighborhoods.
Study host behavior and listing strategies.
Explore the relationship between availability and pricing.

Key Insights:
Hotel rooms have the highest average prices despite low availability, while entire homes and private rooms dominate market supply.
High-listing neighborhoods such as Bedford-Stuyvesant and Williamsburg show competitive pricing despite large supply volumes.
Pricing fluctuates non-linearly across availability levels, indicating dynamic demand-driven pricing rather than simple seasonality.
Multi-listing hosts charge slightly higher prices, suggesting more professionalized pricing strategies.

Skills Demonstrated:
SQL data cleaning & type casting.
NULL handling and data validation.
Aggregations and grouping analysis.
Business-driven exploratory data analysis.
Dashboard design and storytelling.
